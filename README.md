# Sparky — All-in-One Android Utility App

Sparky combines four everyday tools in a Material 3 Jetpack Compose interface:
1. **Smart Calculator:** Standard + Scientific modes (DEG/RAD) with persistent Room history.
2. **Water Reminder & Tracker:** Personalized daily goal calculator, quick-add intake buttons, and WorkManager hydration reminders.
3. **Alarm & Clock:** Exact alarms with repeat days and custom labels, plus Stopwatch (with laps) and Countdown Timer.
4. **To-Do List & Notes:** Priority-ranked tasks with category tags and rich-text style Markdown notes.

## How to Build the APK
1. Extract `SparkyApp.zip`.
2. Open the `SparkyApp` folder in **Android Studio** (Ladybug or newer).
3. Wait for Gradle sync to finish.
4. Connect an Android device (or start an emulator) and click **Run**, or choose **Build > Build Bundle(s) / APK(s) > Build APK(s)** to generate the `.apk`.
